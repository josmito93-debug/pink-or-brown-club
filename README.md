# Pink or Brown · Club

A bold, modern, and celebratory web app & community platform celebrating breast diversity and raising breast cancer awareness.

Every order and challenge entry supports Breast Cancer Awareness initiatives.

---

## ✨ Features

- **Store & Merch Catalog:** Apparel, trucker hats, tees, tanks, socks, briefs with dynamic product visualizer and size/color selection.
- **Cart & Checkout Experience:** Slide-out animated cart drawer with free shipping calculator, points discount slider (100 pts = $1), club code redemption, and order confirmation.
- **POB Challenge & Hot Reveals:** Community photo contest with live voting between Pink & Brown, instant visual percent meters, and entry guidelines.
- **Member Portal & Gamified Dashboard:**
  - Progress ring tracking lifetime points and tier progression (Blush, Rose, Cocoa, Icon).
  - Monthly ranking leaderboard between Team Pink and Team Brown.
  - Interactive badges (First Snap, Linked Up, On a Roll, Challenger, Checked In, Ambassador, Top 10, etc.).
  - Monthly self-check tracker with points bonus.
  - Activity log with full point audit history.
- **Member Messaging (DM):** Direct messaging interface with demo member auto-replies, conversation switcher, reporting, and moderation controls.
- **Rewards Store:** Redeemable vouchers, discount codes, merchandise perks, VIP tickets, and physical sticker packs.
- **GSAP Animations:** High-end motion design including physics-based confetti bursts, floating point feedback, staggered card entrances, drawer slide transitions, and interactive button micro-interactions.
- **Age Gate:** 18+ verification modal complying with adult community guidelines.

## 🛠 Local Development

To run locally with any static server:

```bash
# Using npx serve
npx serve .

# Or using Python
python3 -m http.server 3000
```

Open `http://localhost:3000` in your browser.
